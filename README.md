Data and R code from the article "Altered seasonality links warming to native species declines in the Eastern Mediterranean", 
published in Proceedings B (DOI: 10.1098/rspb)
By Roel Lammerant, Shahar Chaikin, Jonathan Belmaker, Jan Steger, Mai Lazarus, Cesare Bogi, Bella S. Galil, Hadas Lubinevsky, Martin Zuschin, Paolo G. Albano 

This project compiled a large dataset of native and non-indigenous fishes and molluscs sampled in the eastern Mediterranean Sea to assess their seasonal abundance patterns across gradients of summer temperatures. 
We assume that changes in seasonal abundance between spring and autumn provide an integrative signal of how summer conditions influence population trajectories.

All the R-code for this project can be found in the CODE folder, with all the files ordered in sub-folders which refer to the main analyses performed in this study.
The names of the specific R-files, inform you about which part of the analyses, data assembly or output is performed with the specific file.
All the Raw data used in this project can be found in the DATA folder, while compiled datasets used in our analyses can be in output_data.
Finally, output_plot stores all the figures that were created in this project.
